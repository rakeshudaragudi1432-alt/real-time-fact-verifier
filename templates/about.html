About FactVerify AI

FactVerify AI is a real-time claim verification system that evaluates natural-language statements against live external APIs and authoritative scientific reference databases.

⚡ How Verification Works

1

Claim Submission

The user inputs a natural language statement (e.g. "Today the temperature in Vijayawada is 28°C").

2

Domain Identification

The Claim Analyzer classifies the statement into Weather, Sports, Movies, Science, or Unknown.

3

Live API Query

The system queries specialized live REST APIs (Open-Meteo, TheSportsDB, OMDb/IMDb, Wikimedia, NASA).

4

Evidence Comparison

The Verification Engine parses parameters (temperatures, scores, release years, directors) and compares claim vs evidence.

5

Result Generation

Returns a verified outcome status: VERIFIED ✅, NOT VERIFIED / FALSE ❌, or UNCERTAIN ⚠️.

6

Attribution & Audit

Displays extracted evidence metrics, explanation details, source name, and direct clickable source URLs.

🌐 Supported Verification Domains

🌤️

Weather Verification

Fetches current real-time atmospheric data (temperature, rain status, humidity, cloud cover) via Open-Meteo REST API.

🏆

Sports Verification

Queries live and recent match records, scorelines, team winners, and tournament statuses via TheSportsDB REST API.

🎬

Movie Verification

Retrieves film release dates, directors, cast members, genres, and IMDb ratings via OMDb / IMDb REST API.

🔬

Science Verification

Queries verified scientific facts, physical properties, planetary data, and astronomy records via Wikimedia REST API & NASA Open Science API.

⚠️

Important Note

FactVerify AI performs evidence-based verification using live structured API feeds. It is designed to demonstrate real-world API data verification and should be evaluated alongside authoritative primary literature.
